# Текущее состояние и путь к v1

- Актуально на: 2026-07-26
- Текущая версия: `v1.0.0-beta.3`
- Следующий стабильный тег: `v1.0.0`, только после снятия релизных блокеров

Этот документ является основной таблицей правды. Он описывает работающий код,
а не желаемую будущую архитектуру.

## Значения статусов

| Статус | Смысл |
|---|---|
| Готово в beta | Пользовательский сценарий реализован и имеет базовые проверки |
| Частично | Полезная часть работает, но заявлять полную готовность нельзя |
| Эксперимент | Код существует, но не входит в обычный пользовательский путь |
| Отложено | Не входит в обещания текущей beta |

## Что готово

| Область | Статус | Что работает |
|---|---|---|
| Учётные записи и сессии | Готово в beta | Регистрация, вход, refresh, выход, выход со всех устройств |
| Канбан-ядро | Готово в beta | Workspace, доски, колонки, карточки, архивирование, удаление, перенос и сортировка |
| Карточка | Готово в beta | Заголовок, описание, статус, приоритет, даты, метки, чек-листы, комментарии |
| Внешний вид | Готово в beta | Настройки пользователя и доски |
| История | Готово в beta | Activity для доски/карточки и audit для workspace |
| Local-first | Частично | Snapshot, тёплый старт, offline-правки карточек, очередь и видимые состояния sync |
| Backend sync | Частично | Реплики, idempotent push, pull по cursor, tombstones, `serverOrder` |

## Что не является готовой функцией

- клиент ещё не применяет весь входящий sync-log к локальным проекциям;
- coordinator-free права и подписи устройств не реализованы;
- Nostr/Iroh не включаются обычным bootstrap;
- import умеет восстановить одну доску как новую копию, но не workspace, merge
  или destructive replace;
- conflict-resolution UI не завершён;
- integrations/webhooks в основном остаются контрактами и адаптерами;
- mobile-клиента для реального использования нет;
- локальный snapshot не зашифрован;
- вложения не входят в backup bundle.

## Обычный пользовательский путь

1. Запустить `python bootstrap.py`.
2. Зарегистрироваться.
3. Создать workspace, доску и колонки.
4. Создавать, редактировать и переносить карточки.
5. Использовать метки, чек-листы и комментарии.
6. Смотреть историю и менять внешний вид.
7. Выгрузить backup.
8. При необходимости импортировать board backup как новую копию.
9. Остановить stack через `python bootstrap.py stop`, не теряя данные.

## Почему это beta.3, а не stable v1

Предыдущий подтверждённый полный прогон от 2026-06-04 относился к линии
beta.2 и состоянию до новых транспортов и zero-config bootstrap. Он остаётся
полезным историческим доказательством, но не подтверждает новую упаковку.

Перед stable `v1.0.0` обязательны:

1. повторный `full-local-release` на текущем commit;
2. сборка архива из точного тега;
3. запуск распакованного ZIP на чистой Windows-машине;
4. запуск того же ZIP на Linux;
5. повторный старт с сохранением данных;
6. проверка reset только на тестовых данных;
7. исправление всех найденных дефектов и ещё один повторяемый прогон;
8. решение о лицензии перед публичным распространением.
