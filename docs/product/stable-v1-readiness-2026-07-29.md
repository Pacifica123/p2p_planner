# Оценка готовности stable v1

- Дата: 2026-07-29
- Проверяемая линия: `v1.0.0-beta.6`
- Вердикт: функционально близко, релизно ещё не готово

## Что изменилось в оценке

Старый список блокеров был составлен до beta.4–beta.6 и ошибочно смешивал
недостающие функции с недостающими доказательствами. Основной web CRUD,
чек-листы, комментарии, внешний вид, bootstrap и полезный Android-клиент уже
существуют. Удерживать stable из-за отсутствия GitHub, Iroh или полного
coordinator-free режима больше не требуется.

Текущие блокеры относятся к воспроизводимости, данным и честной границе
релиза.

## Матрица доказательств

| Область | Текущее доказательство | Оценка | Что нужно до stable |
|---|---|---|---|
| Web CRUD | unit/build и длительное полевое использование | сильный сигнал | итоговый artifact smoke |
| Сохранение данных | владелец успешно использует продукт с beta.3 | полезный полевой сигнал | scripted stop/start/update/rollback |
| PostgreSQL backup | updater создаёт custom `pg_dump` и manifest | реализация есть | restore drill на копии данных |
| Web → Android | ранее наблюдалось в рабочем сценарии | частично подтверждено | повторить на beta.6 |
| Android → web | причина найдена и исправлена в обоих клиентах/backend | кодовый сигнал | ручная cross-client матрица |
| Android CRUD | TypeScript/unit/Metro проверки патча | кодовый сигнал | APK acceptance на реальном устройстве |
| Windows bundle | старые прогоны не покрывают beta.6 | недостаточно | чистая Windows |
| Linux bundle | старые прогоны не покрывают beta.6 | недостаточно | чистый Linux |
| Import-as-copy | автоматические проверки контракта | частично | smoke итогового ZIP |
| Лицензия | файл лицензии отсутствует | блокер решения | выбрать лицензию или явно не публиковать |
| Секреты в ZIP | builder исключает типовые пути | хороший статический сигнал | финальный scan собранного файла |

## Причина бага Android → web

Проблема состояла из трёх независимых частей:

1. при наличии roaming capability Android публиковал операцию сразу в relay и
   удалял её из очереди, не отправляя доступному coordinator;
2. roaming-ingest пытался записать мобильный статус `todo`, тогда как
   PostgreSQL принимает `active`, `completed` или `cancelled`;
3. открытая web-доска не обновляла список карточек автоматически.

Beta.6 меняет порядок на coordinator-first с relay fallback, нормализует
статусы и обновляет активные web-запросы. Это закрывает найденную техническую
причину, но не отменяет проверку на реальных устройствах.

## Обновлённые критерии stable

Stable можно выпускать, если одновременно выполнены условия:

1. точный tagged commit дважды проходит
   `release-gates --profile full-local-release`;
2. один и тот же ZIP запускается на Windows и Linux;
3. тестовые данные переживают stop/start, update, rollback и отдельный restore;
4. cross-client CRUD проходит в обе стороны;
5. граница Android объявлена явно и соответствует результатам проверки;
6. лицензирование решено;
7. опубликованы SHA-256 и evidence bundle без секретов.

## Что не должно задерживать v1

GitHub/devctl, другие providers, coordinator-free membership, Iroh в web,
MFA/passkeys и destructive import — следующие продуктовые срезы. Их отсутствие
должно оставаться в limitations, а не превращаться в бесконечный релизный
блокер.
